# ЧМ-2026 — База игроков

Интерактивная база всех футболистов, вызванных в составы сборных на Чемпионат мира 2026.

Фильтры по сборной, клубу, стране клуба, лиге и позиции, поиск по имени, сортировка по любой колонке. Статичный сайт без бэкенда — работает на GitHub Pages.

## Данные

- 1241 игрок, 48 сборных, 460 клубов.
- Источник: [Championat.com](https://www.championat.com/football/article-6475914-sostavy-sbornyh-na-chempionat-mira-2026-zayavki-na-chm-2026-polnyj-spisok-igrokov-kto-poedet-na-chm-kto-ne-popal-v-spiski.html) (составы на 02.06.2026).
- Названия клубов и лиг нормализованы вручную.

## Структура

- `index.html` — страница с интерфейсом и логикой фильтрации.
- `data.js` — встроенная база игроков (`const PLAYERS = [...]`).

Чтобы обновить данные — замените массив в `data.js`.
